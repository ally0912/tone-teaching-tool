📊 7 種口氣對比表

口氣類型 適用場景 核心特徵 禁止用語
正式專業型 商務、法務、學術 敬語 + 複句 + 正式詞彙 口語、不夠莊重
親切積極型 銷售、客服、推廣 熱情 + 短句 + 驚嘆號 冷漠、距離感
謹慎理性型 分析、評估、法務 中立 + 條列 + 邏輯性 絕對化、猜測
輕鬆幽默型 社群、內部、品牌 梗 + 短句 + 自然 冒犯、過度不專業
冷靜技術型 技術文檔、問題排查 步驟 + 去感情 + 邏輯清 模糊詞、情感詞
鼓勵教練型 教學、激勵、諮詢 信心 + 陪伴 + 正面 空洞雞湯、低估
嚴肅警告型 安全、紀律、危機 直接 + 強調 + 後果 開玩笑、弱化
